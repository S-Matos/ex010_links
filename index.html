Detalhes da tag <a> (âncora) e seus atributos.

A tag <a> é usada para criar links em uma página da web.

Atributos importantes da tag âncora:

href Significa: Hyperlink Reference (referência do link). É o endereço para onde o link vai te levar.

target Indica onde o link será aberto.

Os dois mais usados:

_self: abre na mesma aba (padrão).

_blank: abre em uma nova aba.

rel Significa: relationship (relação). Diz qual é a relação entre a sua página e o link. Importante para segurança e SEO.

Exemplos comuns de rel:

rel="noopener noreferrer": usado com target="_blank" para evitar riscos de segurança.

rel="nofollow": diz aos buscadores para não seguirem aquele link (útil para links pagos ou patrocinados).

Resumo:

  • <a>: cria o link.
  • href: diz pra onde o link vai.
  • target: diz como o link será aberto.
  • rel: diz qual é a relação com o link, usado por segurança ou SEO.
